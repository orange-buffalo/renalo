Chat is an optional AI assistant. A deployment operator enables it and configures LiteLLM as described in [Install with Docker](/getting-started/installation/); when disabled, Chat does not appear in the main navigation.

Renalo uses the configured AI model to answer questions through read-only access to your accounts, category totals, transactions, net worth, and funds transfers. Amounts, date filtering, currency projections, balances, and analytics remain calculated by Renalo rather than by the model. A new chat also receives a concise generated title based on its first prompt.

## Try the interface

- Select **New conversation** to add another conversation.
- Use the conversation selector to move between their separate message feeds.
- Write a message and press **Enter** or select the send button. Use **Shift + Enter** for a new line.
- Review the activity labels to see when Renalo is calculating or searching financial data for the answer.

Conversation names persist across browser reloads. Renalo reloads message history when the conversation has a stored LiteLLM response chain. If that external state is temporarily unavailable, the chat remains listed and offers a retry action without replacing or clearing the saved session.

<Aside type="caution" title="AI-generated explanations">
  The model can make mistakes when interpreting tool results. Verify important decisions against Renalo's regular dashboards and transaction pages. Your prompts and the financial data needed to answer them are sent through the configured LiteLLM deployment and may be processed by its model provider.
</Aside>
