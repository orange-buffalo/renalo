AI chat is an optional assistant for regular users exploring the financial data already stored in Renalo. A deployment operator enables it and configures LiteLLM as described in [Install with Docker](/getting-started/installation/). When it is disabled, **Chat** does not appear in the navigation; administrators do not have access to it.

## Ask about your Renalo data

AI chat can analyze, summarize, compare, visualize, and explain your own Renalo data. It has read-only tools for:

- active account balances and current-month money flow;
- income and expense totals by category;
- transactions filtered by dates, accounts, categories, notes, currencies, amounts, recurrence, and import source;
- income and expense trends over time;
- net worth through today; and
- funds transfers.

Renalo remains responsible for authorization, date filtering, balances, currency projections, and exact financial calculations. The model interprets those results and writes the answer. It cannot edit transactions, accounts, categories, transfers, or settings.

Answers stream into the feed and can contain headings, lists, tables, diagrams, and other structured Markdown. Safe Renalo-owned activities such as **Calculated category totals** explain what the app is doing without exposing hidden model reasoning, raw tool arguments, or raw results. Adjacent tool calls are grouped into concise summaries.

Type a message and press **Enter** or select **Send message**. Use **Shift + Enter** for a new line. While a response is running, the send control becomes **Stop response**; stopping keeps output that has already arrived.

On mobile, Chat fills the screen below the topbar. The message feed is the only scrolling region, while the conversation controls and composer remain available around it. Charts use the full feed width and interactive panels open full screen.

## Conversations and history

An empty **New chat** remains only in your browser until its first message is accepted. Renalo then saves the conversation and generates a concise title from that prompt.

Use the conversation selector to switch between chats or start another one. The actions beside the title let you rename or delete the current conversation. Saved messages, charts, activity summaries, and turn metrics survive reloads because Renalo stores its own conversation event log rather than relying on provider-side response history.

## Charts

Ask for a useful visualization or let the assistant choose one for the question. AI chat supports line, area, vertical and horizontal bar, pie, donut, and scatter charts, including multiple series and stacked data. Chart values come from successful read-only Renalo tools and retain exact currency or numeric values for tooltips and the accessible data table.

## Time, tokens, and context

Each completed assistant turn shows its elapsed time and, when the provider supplies it, the number of tokens consumed across the turn. These values are best-effort operational information and do not change the financial result.

The circular indicator above **Send message** shows the latest estimate of how much model context the conversation occupies. Select or hover over it for the current and maximum sizes. If the operator configured the model's maximum context and the estimate reaches 75%, the indicator warns you to start a new chat. If the maximum is unknown, Renalo warns that an unexpectedly full context may cause the chat to fail.

<ScreenshotPair
  desktop={contextDesktop}

Renalo does not compact long conversations or automatically replace them. Keep chats focused and start a new one before the context becomes full.

## Changing topics

For a significant change to another in-scope financial analytics topic, the assistant can pause before answering and recommend a separate chat. The recommendation is not used for ordinary follow-up questions, corrections, refinements, or closely related analysis.

<ScreenshotPair
  desktop={topicChangeDesktop}
  mobile={topicChangeMobile}
  alt="An AI chat topic-change recommendation with continue-here and new-chat actions"
/>

- **Continue in a new chat** moves the pending question through the normal new-chat flow and leaves the previous conversation focused on its original topic.
- **Continue here** resumes the same turn in the current conversation.

The decision remains available after a reload. While it is pending, the composer is disabled so the question cannot be submitted twice.

## Scope and limitations

AI chat is restricted to analyzing and explaining the authenticated user's financial data available through Renalo. It declines unrelated general questions, writing or coding tasks, and requests for financial advice or recommendations about what you should do. For a mixed request, it can address the in-scope analysis and decline the rest.

Instructions found in messages, saved conversation content, transaction notes, imported data, or tool results cannot change that scope. Out-of-scope requests are declined rather than moved to a new chat.

<Aside type="caution" title="AI-generated explanations">
  The model can still make mistakes when interpreting authoritative tool results. Verify important conclusions against Renalo's regular dashboard and transaction pages. AI chat explains financial data; it is not financial advice.
</Aside>

## Privacy and deployment

The browser communicates only with authenticated Renalo endpoints, and the LiteLLM API key remains on the server. Tool queries are scoped to the signed-in user, and the model cannot select another user ID.

Your prompts, relevant financial data, and generated responses pass through the configured LiteLLM deployment and may be processed or retained by its model provider. Deployment operators should review those systems' privacy and retention terms. A locally hosted model behind a private LiteLLM deployment provides the strongest control over where data is processed. Renalo database backups also include saved conversation history.
